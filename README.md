# Galactic Invaders React

"Crea un juego arcade retro 2D completamente funcional en React utilizando HTML5 <canvas>. El estilo visual debe ser estrictamente 8-bit pixel art, inspirado en los clásicos del espacio.

Aspecto Visual: El fondo debe ser un espacio oscuro continuo con pequeñas estrellas cuadradas blancas moviéndose hacia abajo. Usa una fuente tipográfica blocky/arcade para la interfaz. Arriba a la izquierda muestra 4 vidas (representadas por pequeños íconos verdes) y arriba a la derecha el puntaje (score) en color verde neón.

Nave del Jugador: Ubicada en la parte inferior central. Debe moverse fluidamente de izquierda a derecha usando las flechas del teclado y disparar láseres segmentados celestes hacia arriba al presionar la barra espaciadora.

Enemigos: Genera una formación en cuadrícula (ej. 3 filas y 6 columnas) de enemigos alienígenas morados en la parte superior. Toda la formación debe moverse en bloque de izquierda a derecha y descender un paso cada vez que tocan los bordes de la pantalla.

Combate y Efectos: Si el láser del jugador impacta a un enemigo, debe reproducirse un efecto visual de explosión de partículas naranjas y rojas, sumar puntos y destruir al enemigo. Los alienígenas deben disparar proyectiles hacia abajo de forma aleatoria.

Estados del Juego: Implementa una pantalla de 'Press Start' para iniciar y una pantalla de 'Game Over' cuando las vidas del jugador lleguen a cero."
